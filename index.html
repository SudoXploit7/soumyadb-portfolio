DefenSight AI

Autonomous Network Defense Copilot — an AI-powered security log analysis platform that transforms raw firewall, IDS, and network logs into actionable intelligence using RAG and LLMs. Multi-format ingestion (CSV, XML, JSON, LOG, TXT), intelligent normalization with automatic type detection, semantic search via 768-dimensional vector embeddings (ChromaDB + HNSW), and Groq LLaMA 3.3 70B integration with 128k context. Generates technical and executive summaries, exports PDF reports, delivers email-based report delivery, and provides an interactive SOC chat assistant — all behind a multi-user Flask auth system with bcrypt hashing.
